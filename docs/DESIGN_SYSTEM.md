# Filosofía

CompuMercado debe transmitir:

- Profesionalismo
- Confianza
- Tecnología
- Seguridad
- Innovación
- Simplicidad

No diseñamos para impresionar.

Diseñamos para generar confianza.

# Filosofía de Desarrollo

No copiar componentes.

No duplicar lógica.

No escribir código sin propósito.

Cada componente debe responder:

¿Genera confianza?

¿Es reutilizable?

¿Aporta valor al usuario?

Si la respuesta es no...

No pertenece al proyecto.

# Objetivo

Construir una experiencia web que represente la calidad de los servicios de CompuMercado y que convierta visitantes en clientes.
